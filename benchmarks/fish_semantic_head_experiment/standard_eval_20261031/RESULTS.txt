Interpretation:
The tied output head projects only semantic and EOS weight rows, then reconstructs vocabulary-shaped logits with negative infinity elsewhere. The existing sampler and original token IDs are unchanged. Live weight views preserve weight updates; the full shared input embedding remains resident. No async decode, fixed slots or state-update fusion is enabled.
All per-pass results are disclosed. The shared host, stochastic sampling and dynamic batching limit interpretation of small throughput differences; two passes are descriptive evidence rather than a formal performance confidence interval.
Evidence is archived on experiment/fish-semantic-head. The clean implementation branch perf/fish-semantic-head is reserved for upstream review.

Validation: 183 CPU regressions; 60 projection checks including tied/untied output, live weight updates, CUDA Graph replay, full output shape and no-VQ fallback. Real-model semantic and all 10 codebooks match bitwise in 12/12 cases for dynamic graph buckets and 12/12 for fixed batch 8, including EOS, reference audio and cancellation recovery.
